# LageInfo

Experimentelle, modulare Lageübersicht für öffentlich verfügbare Informationen.

Geplante Module:
- Deutschlandlage mit Polizei-/Pressemeldungen und Warnungen
- frei definierbare Schlagwortfilter
- Weltlage mit öffentlich bekannten Einsatz-/Missionsregionen
- GDELT-Nachrichten
- USGS-Erdbeben
- NASA FIRMS-Brände
- Open-Meteo-Wetter
- öffentliche ADS-B-Luftlage
- CelesTrak-Satelliten
- optional AIS-Schiffsverkehr

Grundsatz: keine nichtöffentlichen oder operativ sensiblen Positionsdaten. Datenquellen bleiben getrennte Module, damit Ausfälle einzelner Dienste die Oberfläche nicht blockieren.
